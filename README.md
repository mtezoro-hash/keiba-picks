# 競馬予想の公開記録（M1S）

中央競馬（JRA）の予想モデル「M1S」の予想を、**発走前に**この置き場へ自動で記録しています。
同じ内容を X（[@mtezoro](https://x.com/mtezoro)）にも発走前に投稿します。

- 記録はすべて発走前に書き込みます。書き込んだ時刻は、この置き場の履歴（コミットの時刻）で誰でも確かめられます。
- 結果は**負けも含めて全部**残します。後から消したり書き換えたりしません。
- 成績は「的中率」と「回収率」で示します。

## ファイル

| ファイル | 中身 |
|---|---|
| `picks.csv` | 予想（記録した時刻・開催日・競馬場・レース・発走時刻・馬番・馬名・券種） |
| `results.csv` | 結果（着順・払戻）。レース後に追記します |

## M1S とは

市場（オッズ）を出発点にして、勝つ確率を補正するモデルです。発走5分前の時点で、
期待値 1.05 以上・単勝20倍以下の馬のうち、1レースに1頭だけを選びます（単勝・1点100円の紙の記録）。

## ご注意

- これは個人の予想の記録で、利益を約束するものではありません。これまでの回収率は 1 を下回っています。
- 馬券の購入は20歳以上・自己責任でお願いします。
- オッズなどのデータそのものは載せていません。
