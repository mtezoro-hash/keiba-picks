# 競馬予想の公開記録（M1S）

中央競馬（JRA）の予想モデル「M1」の安定形「M1S」の予想を、**発走前に**この置き場へ自動で記録しています。
同じ内容を X（[@mtezoro](https://x.com/mtezoro)）にも発走前に投稿します。

- 記録はすべて発走前に書き込みます。書き込んだ時刻は、この置き場の履歴（コミットの時刻）で誰でも確かめられます。
- 結果は**負けも含めて全部**残します。後から消したり書き換えたりしません。
- 成績は「的中率」と「回収率」で示します。

## M1 とは

単勝の「勝つ確率」を予想する機械学習のモデルです。

1. **出発点は市場（オッズ）**：発走5分前の単勝オッズから、その馬の「市場が見ている勝率」を出します。
2. **市場のずれだけを学ぶ**：過去の成績、血統、調教、馬体重、騎手や調教師の傾向などから、
   市場の勝率がずれていそうな分だけを補正します（木を組み合わせる機械学習。レースごとに勝率の合計が1になるように計算）。
3. **期待値を出す**：補正した勝率 × その馬が勝ったときの払戻の見込み ＝ 期待値（1.0 を超えると、理屈の上では得）。

使うのは**発走5分前に見える情報だけ**です。確定オッズやレース結果は、予想には使いません（払戻の計算にだけ使います）。
学習は2020年以降のレースで行い、検証は学習に使っていない年で行っています。

## M1S とは（このページで公開しているもの）

M1 の中から、ぶれの小さい形に絞ったものです。

- 期待値 1.05 以上
- 発走5分前の単勝オッズが 20倍以下
- 1レースに1頭だけ（期待値がいちばん高い馬）
- 単勝・1点100円の紙の記録として数えます

## これまでの成績（正直に書きます）

| 区分 | 期間 | 点数 | 的中率 | 回収率 |
|---|---|---|---|---|
| 研究（学習に使っていない年） | 2022〜2026年8月 | 年350〜985点 | — | 年ごとに 1.15 / 1.14 / 1.07 / 1.08 / 1.13 |
| 発走前に実際に判定した記録（紙） | 2026-08-22〜10-03 | 56点 | 12.5% | 0.970 |

- 研究の数字は、絞り方（20倍以下など）を過去の結果を見たあとに決めた部分があり、そのぶん良く出ている可能性があります。
- 発走前の実際の記録は、まだ点数が少なく、回収率は 1 を下回っています。
- 馬券には約20%の控除があり、長い目で 1 を超え続けるのはとても難しいことです。
