# 競馬予想の公開記録（AIの予想）

中央競馬（JRA）の予想を、自作の AI（学習モデル「M1」）が**発走前に**選び、この置き場へ自動で記録しています。
同じ予想を X（[@mtezoro](https://x.com/mtezoro)）にも発走前に自動で投稿します。運営は本人です。

- 予想は、AI の判定の直後（発走の約5分前）にここへ書き込み、そのあとで X に投稿します。書き込んだ時刻は、この置き場の履歴（コミットの時刻）に残ります。
- GitHub へ送れなかったときは X を先に出し、記録は次の機会に送ります。判定が発走の1分前より遅れた馬は X に出さず、ここに「公開しなかった馬」として残します。
- 結果は**外れも含めて全部**残します。後から消したり書き換えたりしません。間違いがあったときは、訂正を新しく書き足します。
- 通算の記録は **2026年10月10日** から数えます。

## 予想の出し方

- AI が選んだ馬（発走5分前の単勝が100倍未満の馬）を**全部**出します。1レースに何頭でも**全部◎**で、順位は付けません。券種は**単勝**です。
- 成績は**レース単位**で「○戦○勝」と数えます（1レースに何頭選んでも1戦。どれかが1着なら1勝）。
- 単勝を1頭100円ずつ買ったとして「100円ずつ ○円→○円」で示します。取消・除外の馬は数えません（全部の馬が取消・除外になったレースと、中止のレースは0戦）。
- 着順と払戻は **JRA 公式サイトの発表**（100円あたり）の値です。
- 回収率は、通算が**30戦**に届いてから、毎晩の答え合わせで出します（1を下回っていても出します）。
- 開催日の流れ：発走前に【AIの◎】→ 夜に【AIの予想 答え合わせ】。重賞（G1〜G3）で AI が選ばなかったときは「AIは見送り」と出します。

### 単勝100倍以上の馬について

発走5分前の単勝が100倍以上の馬は X に出しません。この置き場には「公開の条件の外」として、ほかの馬と同じく発走前に記録します。
この線は **2026年10月4日の夜、それまでの発走前の記録を見た後に決めました**。結果を見てから決めた線なので、そのことも含めてここに残します。

## 重賞の見どころ（AIの注目・AIの評価）

重賞では、出走の登録の後に「過去の傾向」を、枠順が決まった後に AI が作った見どころを出します。

- **AIの評価**：出走馬ごとに「舞台」と「近況」を A / B / C で示します。
- **AIの注目**：AI が注目する馬と、注意したい馬です。
- 評価の付け方は公開しません。
- 見どころは、上の予想（AIの◎）とは**別の仕組み**です。見どころで注目した馬と、AIの◎が違うことがあります。

## M1 とは

単勝で1着になりそうな馬を選ぶ、自作の機械学習のモデル（AI）です。
使うのは**発走5分前に見える情報だけ**で、レースの結果を予想に使うことはありません。
選び方の細かい決まりは、誤解を招くので載せません。決まりは公開を始める前に決め、途中で変えるときは日付つきでここに書きます。
